# Road-Ticket-Management (This README file is subject to continuous change as I learn and document my progress.)

This is unofficially the second version and officially the first version of the Road Ticketing Management Project.
This version does not have the issues I encountered in Road-Ticket-Management, and I have successfully integrated all the features I mentioned in the README.md file of Road-Ticket-Management that V1 was meant to have.

Mentioned Features:
Features for (V1)

- Sign In and Log In. (Authentication)
- Profile creation. (CRUD)
- Ticket creation for officials. (CRUD)
- Frontend for ticket monitoring. (CRUD)
- Means for disputing tickets for motorists. (CRUD)
- Means to pay for tickets. (CRUD)

As stated in Road-Ticket-Management, this project was intended to solve a problem in my home country Nigeria and also serve as a means of Project based learning. I intend to continue to modify and add more features as I go to build a concrete product.
